# Conversation – The Falcons (Page 17)

موقع تعليمي تفاعلي ثابت (HTML / CSS / JavaScript) لدرس اللغة الإنجليزية «Conversation» – الصفحة 17، جاهز للنشر على GitHub Pages. لا يعتمد على أطر عمل أو خدمات خلفية أو مفاتيح API.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة والبطاقات |
| `style.css` | التصميم والأنيميشن (CSS/SVG) |
| `script.js` | الحوار التفاعلي، Real Talk، الاختبار، المؤقت |
| `sw.js` | تخزين الملفات للعمل دون اتصال (اختياري) |
| `manifest.webmanifest`, `icon.svg` | بيانات التثبيت والأيقونة |

## التشغيل محليًا

**الأسهل:** افتح `index.html` مباشرة في المتصفح (كل شيء يعمل عدا التخزين دون اتصال).

**عبر خادم محلي** (لتجربة العمل دون اتصال):

```bash
cd falcons-lesson
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `falcons-conversation`).
2. ارفع محتويات المجلد (الملفات في جذر المستودع، وليس المجلد نفسه).
3. من المستودع: **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
5. بعد دقائق يظهر الرابط: `https://USERNAME.github.io/REPO-NAME/`

جميع المسارات نسبية، لذا يعمل الموقع داخل مسار المستودع دون تعديل.

## ملاحظات

- الحوار **مرئي فقط**: يُبرز السطر الحالي دون أي ملف صوتي.
- خيار **تقليل الحركة** في الشريط العلوي، والموقع يحترم أيضًا إعداد `prefers-reduced-motion` في الجهاز.
- عند تحديث الملفات بعد النشر، غيّر رقم `CACHE` في `sw.js` (مثل `falcons-lesson-v2`) ليحصل الطلاب على النسخة الجديدة.
- إن أردت إضافة درس آخر لاحقًا، ضعه في مجلد فرعي داخل المستودع.
